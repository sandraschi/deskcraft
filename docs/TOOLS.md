# deskcraft MCP tools

Generated by `deskcraft tools --markdown`. Do not edit by hand: a test fails when this file
is out of date. Every tool is also a CLI verb (`deskcraft --help`). Dotted names (`app.verb`) are accepted.

| Tool | What it does | Required | Optional |
|---|---|---|---|
| `desk_status` | Ticket counts by status, messages, unsent drafts, support address, outbox folder. | - | - |
| `desk_config` | Show or set the support address (mails from it count as our replies), the sender name and the reply signature. | - | `signature`, `support_address`, `support_name` |
| `desk_ingest` | Read .eml files or a maildir (cur/new) into tickets. Threads by Message-ID / In-Reply-To / References, then [D-n] subject tags, then same requester + subject within 30 days. Re-ingesting is a no-op. dry_run stores nothing. | `path` | `dry_run` |
| `desk_ticket_list` | Tickets, urgent first. Default: new, open and pending. | - | `assignee`, `include_closed`, `priority`, `status`, `text` |
| `desk_ticket_show` | One ticket with all messages, internal notes, history and SLA clocks. | `ticket` | - |
| `desk_ticket_update` | Change status, priority, assignee (null clears), tags (replaces the set) or add an internal note. | `ticket` | `assignee`, `note`, `priority`, `status`, `tags` |
| `desk_reply_draft` | Write a reply as an .eml draft into the outbox (threaded headers, [D-n] in the subject). Nothing is sent. body or macro; {{name}}, {{first_name}}, {{ticket}}, {{subject}}, {{agent}} are filled. | `ticket` | `body`, `macro` |
| `desk_reply_mark_sent` | Mark a reply draft as sent (after sending it from your mail client). The first sent reply stops the first-response clock. | `message` | `at` |
| `desk_macro_set` | Create or change a reply macro, optionally setting a status and adding tags when used. | `name`, `body` | `add_tags`, `set_status` |
| `desk_macro_list` | Reply macros. | - | - |
| `desk_sla_status` | First-response and resolution clocks of open tickets in business hours (Mon-Fri 08:00-17:00, AT holidays excluded): met, ok, at_risk, breached. | - | `as_of` |
| `desk_escalate` | Send a ticket to taskcraft as ticket.escalated (becomes an issue there). Once per ticket; tags it escalated. | `ticket` | `details`, `project` |
| `desk_signals` | Tickets whose customer mails read as unhappy (deterministic DE/EN keywords, not AI). emit=true sends signal.negative to gaincraft once per ticket. | - | `emit` |
| `desk_demo_seed` | Fill an EMPTY desk with labelled demo mails (MIME encoded, threaded, one angry customer) and macros. | - | - |

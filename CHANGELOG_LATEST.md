# deskcraft v0.2.0

Mail-to-ticket desk with threading and business-hours SLAs. Local, one SQLite file. Windows x64.

## Downloads

- `deskcraft-app.exe`: the desktop window.
- `deskcraft.exe`: CLI and MCP server.
- `deskcraft-0.2.0-setup.exe`: per-user installer.
- `deskcraft-v0.2.0.mcpb`: MCP bundle.

## What is new

- Desktop window on the shared suite frame: ticket table, SLA clocks, reply drafts, and escalation to taskcraft.
